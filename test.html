定義 1. 確率分布(p1, …, pn)に対し、そのシャノン情報量を $$H(p_1,\dots,p_n)\coloneqq\sum_{i=1}^{n}-p_i\log_2{p_i}$$ と定める。

シャノン情報量は、その状況で得た情報量の大きさが持つべき性質をいくつか持っているが、逆にその性質から情報量を定める関数が一意に定まることを主張するのが次の定理である。

定理 1 (第二回スライド47枚目). 関数 H : {(p1, …, pn) ∣ n ∈ ℕ, pi ≥ 0, p1 + … + pn = 1} → ℝ であって次の5条件

  1. $\displaystyle H\left(\frac{1}{2},\frac{1}{2}\right)=1$

  2. 任意のnと任意の(p1, …, pn)で$\displaystyle H(p_1,\dots,p_n)\leq H\left(\frac{1}{n},\dots,\frac{1}{n}\right)$

  3. H(p, 1 − p)はpについて連続

  4. 任意の(p1, …, pn)と任意のiでH(p1, …, pn) = H(p1, …, pi, 0, pi + 1, …, pn)

  5. qi ≔ pi, 1 + … + pi, nとして $$H(p_{1,1},\dots,p_{1,n},p_{2,1},\dots,p_{m,n})=H(q_i,\dots,q_m)+\sum_{i=1}^{m}q_iH\left(\frac{p_{i,1}}{q_i},\dots,\frac{p_{i,n}}{q_i}\right)$$

を満たすものはシャノン情報量のみである。
